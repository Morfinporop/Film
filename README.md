# Фильмы: видеохостинг в Telegram

Один Python-файл `main.py` запускает всё: бота (webhook), HTTP-сервер и Mini App из `index.html`.
Видео переводится в HLS с качествами 144p, 240p, 360p, 480p, 720p и 1080p. Для низкого исходника качество увеличивается (апскейл), поэтому 480p, 720p и 1080p есть у любого фильма. В плеере можно выбрать качество, скорость и субтитры.

## Как устроено

- Бот: `/start` с текстом и кнопкой Mini App. Видео от админа до 20 МБ превращается в фильм. Больше 20 МБ облачный Bot API не отдаёт боту, такие файлы загружаются в Админ-панели Mini App.
- Загрузка через Mini App: файл до 2 ГБ. Видео уходит частями по 8 МБ, каждая часть отдельным коротким запросом с повторами при обрыве сети. Так загрузка не зависит от лимита времени запроса на прокси хостинга. Незавершённые загрузки удаляются при перезапуске.
- Mini App: каталог, поиск, экран фильма (постер на фоне, описание, страна, отзывы в отдельных окнах), VIP, профиль с историей просмотров, Админ-панель (только для персонала). Комментариев нет.
- Плеер собственный (не системный): перемотка мышью и пальцем с превью времени, громкость, качество 144p–1080p и «Авто», скорость 0.25×–2×, субтитры слева внизу без подложки, картинка в картинке, полный экран, двойной клик для перемотки и полного экрана. Клавиши: пробел/K пауза, стрелки и J/L перемотка, ↑/↓ громкость, M звук, F полный экран, C субтитры, P картинка в картинке, `<` и `>` скорость, цифры 0–9 переход к проценту. Позиция просмотра запоминается на устройстве.
- Субтитры: встроенные текстовые дорожки видео извлекаются при обработке (ffmpeg, в WebVTT). Свои субтитры админ загружает в редакторе фильма: SRT, VTT, ASS, SSA, кодировки UTF-8 и CP1251 (конвертация через pysubs2).
- Фильм: название, описание, дата выхода, автор, страна, обложка, VIP-флаг.
- Позиция просмотра сохраняется на сервере для каждого пользователя. При повторном открытии плеер предлагает «Продолжить на MM:SS». История просмотров — в профиле.
- Реклама для пользователей без VIP: ролик и ссылка задаются во вкладке «Реклама» админ-панели (владелец и админы). Ролик показывается дважды за просмотр в случайные моменты, через 3 секунды появляется «Пропустить». Перемотка и пауза во время рекламы недоступны. Фильм по ссылке (TikTok, YouTube) открывается в Mini App.
- VIP: 199 звёзд на месяц (+30 дней), 900 звёзд на год (+365 дней). Годовая подписка даёт скидку 62% относительно 12 месячных (экономия 1488 звёзд). Смотреть VIP-фильмы могут VIP и персонал.
- Роли не продаются. Роли: владелец (OWNER_ID, по умолчанию 7745681987), админ, редактор, пользователь. Владелец выдаёт админов, админ выдаёт редакторов, редактор правит и удаляет только свои фильмы.
- Звёзды от VIP, донатов и покупки прав поступают на баланс бота. Владелец видит баланс, продажи и может сделать возврат.

## Запуск на bothost

1. Переменные окружения (см. `.env.example`): `BOT_TOKEN`, `PUBLIC_URL`, `OWNER_ID`, `DB_PATH=/app/data/film.db`, `PORT=3000`, `BOT_MODE=webhook`.
2. Образ собирается по `Dockerfile`. ffmpeg берётся из пакета `imageio-ffmpeg`, системный ffmpeg не нужен.
3. Проверка: `GET /health` отвечает `ok`.

Локально без HTTPS: `BOT_MODE=polling` и `python main.py`. Mini App тогда не откроется из Telegram.

## Структура

- `main.py` — бот, API, база данных, транскодинг, очередь обработки.
- `index.html` — интерфейс Mini App.
- `static/hls.min.js` — hls.js 1.7.3 (MIT), плеер с выбором качества.
- `data/` — база и медиа (`data/media/<id>/`: исходник, HLS-качества, `subs/`), в Git не попадает.

Зависимости: `aiogram`, `imageio-ffmpeg` (ffmpeg), `pysubs2` (субтитры).

## Оплата и ограничения

- Оплата идёт звёздами (XTR) через `createInvoiceLink`. Сумма проверяется на этапе pre-checkout. Повторная оплата с тем же `charge_id` не зачисляется дважды.
- Годовая подписка сделана разовой оплатой на 365 дней. Автопродления Telegram для срока больше 30 дней не поддерживает.
- Звёзды на балансе бота выводятся через Fragment (BotFather). API вывода у бота нет.
- Возврат звёзд делает владелец в Админ-панели. Возврат VIP-платежа сокращает срок подписки. Роли при возврате не снимаются.

## Старые фильмы

Фильмы, загруженные до этой версии, сохраняют прежний набор качеств. Чтобы получить полный набор 144p–1080p, нажмите «Заново» в админ-панели у фильма.

## Миграции

При старте база обновляется без потери данных. Если старая таблица `films` не позволяет загружать файлы через Mini App, она пересоздаётся, старые строки копируются, а старая таблица сохраняется как `films_old_<время>`. Старая таблица `payments` с несовместимой схемой переименовывается в `payments_legacy_<время>`.


## Субтитры
- Встроенные текстовые дорожки (SRT, mov_text) извлекаются при обработке. Для фильмов, загруженных раньше, нажмите «Заново» в админ-панели.
- Субтитры можно загрузить вручную в редактировании фильма (SRT, VTT, ASS, SSA). Кнопка CC в плеере есть всегда; если дорожек нет, плеер сообщает об этом.

## Очистка и база
- Удаление фильма в админ-панели удаляет его из базы вместе с отзывами, просмотрами и папкой с видео.
- Раз в 6 часов: удаляются папки без фильма в базе, незавершённые загрузки старше суток, кэш аватарок старше недели, строки просмотров удалённых фильмов. История просмотров обрезается до 200 записей на пользователя. После удаления выполняется VACUUM.
