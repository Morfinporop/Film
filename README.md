# Film — Telegram-бот каталога фильмов

Проект состоит из двух файлов:

- `main.py` — бот, вебхук, API и запуск всего проекта: `python main.py`
- `index.html` — страница Mini App (каталог-сетка внутри Telegram)

Плюс `requirements.txt`, `Dockerfile`, `.env.example`.

## Что умеет

- **Админ** (ID из `ADMIN_IDS`) командой `/add` загружает видео или баннер (фото), задаёт название и тип:
  - **🔗 Ссылка** — кнопка «▶️ Смотреть» ведёт на ваш переходник;
  - **▶️ Видео в боте** — фильм проигрывается прямо в Telegram.
- **Пользователи** видят каталог сеткой кнопок (по 2 в ряд) по `/start`.
- Ссылка `https://t.me/<бот>?start=film_<id>` сразу открывает фильм.
- **Mini App** — кнопка меню «🎬 Фильмы» и кнопка в каталоге открывают `index.html`.
- Обновления приходят через **webhook** на порт **3000**.
- Данные — в **SQLite** (`/app/data/film.db`), секреты — в **переменных окружения**.

## Переменные окружения

| Переменная       | Обязательна  | По умолчанию                      | Описание |
|------------------|--------------|-----------------------------------|----------|
| `BOT_TOKEN`      | да           | —                                 | Токен от @BotFather |
| `OWNER_ID`       | нет          | `7745681987`                      | Владелец: полный доступ, назначает админов |
| `ADMIN_IDS`      | нет          | —                                 | Стартовые админы через запятую (остальных назначает владелец) |
| `PUBLIC_URL`     | да (webhook) | —                                 | Публичный HTTPS-адрес без `/` в конце |
| `BOT_MODE`       | нет          | `webhook`                         | `webhook` или `polling` |
| `PORT`           | нет          | `3000`                            | Порт HTTP-сервера |
| `WEBHOOK_PATH`   | нет          | `/webhook`                        | Путь для обновлений Telegram |
| `WEBHOOK_SECRET` | нет          | из `BOT_TOKEN`                    | Секрет проверки запросов от Telegram |
| `DB_PATH`        | нет          | `data/film.db` рядом с `main.py`  | Файл БД. На bothost: `/app/data/film.db` |

## Настройка на bothost

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. В панели бота откройте «Переменные окружения» и добавьте:
   ```
   BOT_TOKEN=токен_от_BotFather
   ADMIN_IDS=ваш_telegram_id
   PUBLIC_URL=https://<домен-бота>
   BOT_MODE=webhook
   PORT=3000
   DB_PATH=/app/data/film.db
   ```
3. Порт приложения — **3000**.
4. Команда запуска: `python main.py` (либо сборка из `Dockerfile`).
5. Папка `/app/data` должна быть **постоянной** (volume), иначе база очистится при перезапуске.
6. В логах должно появиться `webhook установлен: https://<домен>/webhook`.
7. Проверка: `https://<домен>/health` → `ok`.

## Роли и права

| Роль | Что может |
|------|-----------|
| 👑 **Владелец** (`OWNER_ID`) | Всё. Назначает и снимает админов и редакторов. |
| 🛡 **Админ** | Добавлять, править, скрывать и удалять **любые** фильмы. Назначать и снимать **редакторов**. Смотреть статистику. |
| ✏️ **Редактор** | Добавлять фильмы. Править, скрывать и удалять **только свои**. |
| **Пользователь** | Каталог, популярное, поиск, Mini App. |

Роли выдаются прямо в боте: **⚙️ Админ-панель → 👥 Команда → ➕ Редактор / ➕ Админ**, затем пришлите
Telegram ID пользователя или перешлите любое его сообщение. Пользователь получит уведомление.
Назначать можно только роли ниже своей: админ не выдаёт админа, никто не меняет владельца.

## Меню и команды

Кнопки внизу экрана: 🎬 Каталог, 🔥 Популярное, 🔍 Поиск, ℹ️ Помощь, 📱 Mini App,
а для сотрудников ⚙️ Админ-панель.

В админ-панели: ➕ Добавить фильм (мастер в 4 шага), 🎞 Фильмы (список, карточка фильма:
открыть, переименовать, сменить ссылку, скрыть/показать, удалить), 👥 Команда, 📊 Статистика.

Команды: `/start`, `/menu`, `/admin`, `/add`, `/cancel`.

## Локальный запуск

Требуется Python 3.10+.

```bash
pip install -r requirements.txt
export BOT_TOKEN=... ADMIN_IDS=... BOT_MODE=polling
python main.py
```

## Docker

```bash
docker build -t film-bot .
docker run -e BOT_TOKEN=... -e ADMIN_IDS=... -e PUBLIC_URL=https://... -p 3000:3000 -v film-data:/app/data film-bot
```

## Безопасность

- Вебхук защищён заголовком `X-Telegram-Bot-Api-Secret-Token`.
- Баннеры отдаются через `/api/banner/<id>`, поэтому токен бота не попадает в браузер.
- Команды админа доступны только `ADMIN_IDS`; остальным бот не отвечает.
