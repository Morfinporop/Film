# Фильмы: видеохостинг в Telegram

Один Python-файл `main.py` запускает всё: бота (webhook), HTTP-сервер и Mini App из `index.html`.
Видео переводится в HLS с качествами 360p, 720p и 1080p (не выше исходника), в Mini App выбирается качество.

## Как устроено

- Бот: `/start` с текстом и кнопкой Mini App. Видео от админа до 20 МБ превращается в фильм. Больше 20 МБ бот скачать не может, такие файлы загружаются в Админ-панели Mini App (ограничения по размеру нет, ограничивает только диск).
- Mini App: каталог, поиск, экран фильма (постер на фоне, выбор качества, отзывы, комментарии), VIP, профиль, Админ-панель (только для персонала).
- Фильм: название, описание, дата выхода, автор, обложка, VIP-флаг. Фильм по ссылке (TikTok, YouTube) открывается в Mini App.
- VIP: 100 звёзд на месяц (+30 дней), 900 звёзд на год (+365 дней). Смотреть VIP-фильмы могут VIP и персонал.
- Роли: владелец (OWNER_ID, по умолчанию 7745681987), админ, редактор, пользователь. Владелец выдаёт админов, админ выдаёт редакторов, редактор правит и удаляет только свои фильмы.
- Звёзды от VIP, донатов и покупки прав поступают на баланс бота. Владелец видит баланс, продажи и может сделать возврат.

## Запуск на bothost

1. Переменные окружения (см. `.env.example`): `BOT_TOKEN`, `PUBLIC_URL`, `OWNER_ID`, `DB_PATH=/app/data/film.db`, `PORT=3000`, `BOT_MODE=webhook`.
2. Образ собирается по `Dockerfile`. ffmpeg берётся из пакета `imageio-ffmpeg`, системный ffmpeg не нужен.
3. Проверка: `GET /health` отвечает `ok`.

Локально без HTTPS: `BOT_MODE=polling` и `python main.py`. Mini App тогда не откроется из Telegram.

## Структура

- `main.py` — бот, API, база данных, транскодинг, очередь обработки.
- `index.html` — интерфейс Mini App.
- `static/hls.min.js` — hls.js 1.7.3 (MIT), плеер с выбором качества.
- `data/` — база и медиа (`data/media/<id>/`), в Git не попадает.

## Оплата и ограничения

- Оплата идёт звёздами (XTR) через `createInvoiceLink`. Сумма проверяется на этапе pre-checkout. Повторная оплата с тем же `charge_id` не зачисляется дважды.
- Годовая подписка сделана разовой оплатой на 365 дней. Автопродления Telegram для срока больше 30 дней не поддерживает.
- Звёзды на балансе бота выводятся через Fragment (BotFather). API вывода у бота нет.
- Возврат звёзд делает владелец в Админ-панели. Возврат VIP-платежа сокращает срок подписки. Роли при возврате не снимаются.

## Миграции

При старте база обновляется без потери данных. Если старая таблица `films` не позволяет загружать файлы через Mini App, она пересоздаётся, старые строки копируются, а старая таблица сохраняется как `films_old_<время>`. Старая таблица `payments` с несовместимой схемой переименовывается в `payments_legacy_<время>`.
