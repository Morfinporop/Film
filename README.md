# FILM·WEB: Telegram-бот каталога фильмов + Mini App

Проект состоит из двух файлов:

- `main.py`: бот, оплата VIP, поиск, API, стрим видео. Запуск: `python main.py`
- `index.html`: Mini App (каталог, просмотр видео, VIP, поиск)

Плюс `requirements.txt`, `Dockerfile`, `.env.example`.

## Возможности

**Бот**
- Главное меню кнопками: 🎬 Каталог, 🔥 Популярное, 🔍 Поиск, 💎 VIP, 📱 Mini App, ℹ️ Помощь.
- Умный поиск: находит по части слова, с опечаткой и без дефиса («интерстелар» → «Интерстеллар»). Если точного совпадения нет, предлагает похожие названия.
- Кнопка «Похожие фильмы» под каждой карточкой.
- VIP-фильмы: закрыты для обычных пользователей, открываются по подписке.
- **VIP-подписка за Telegram Stars.** Тарифы: 1 месяц (150 ⭐), 3 месяца (390 ⭐), 1 год (1290 ⭐). Оплата встроенная, отдельный платёжный провайдер не нужен. Срок продлевается от текущего окончания. Повторное уведомление об оплате не выдаёт VIP дважды.
- Админ-панель кнопками: мастер добавления фильма, управление фильмами, команда (роли), выдача VIP вручную, статистика.

**Mini App**
- Просмотр видео прямо в приложении, с перемоткой.
- Поиск с подсветкой похожих результатов, фильтры, популярное.
- Экран VIP с тарифами; покупка открывает бота.
- Профиль со статусом и ролью. Подпись `initData` проверяется на сервере.
- Дизайн в стиле Spider-Man: красно-синяя палитра, фон-картинка, паутина, SVG-иконки без эмодзи.

**Роли**
- 👑 Владелец (`OWNER_ID`): полный доступ, назначает админов и редакторов.
- 🛡 Админ: любые фильмы, назначает и снимает редакторов, выдаёт VIP, видит статистику.
- ✏️ Редактор: добавляет фильмы, правит и удаляет только свои.
- Пользователь: каталог, поиск, VIP.

## Переменные окружения

| Переменная       | Обязательна  | По умолчанию                     | Описание |
|------------------|--------------|----------------------------------|----------|
| `BOT_TOKEN`      | да           | —                                | Токен от @BotFather |
| `OWNER_ID`       | нет          | `7745681987`                     | Владелец бота |
| `ADMIN_IDS`      | нет          | —                                | Стартовые админы через запятую |
| `PUBLIC_URL`     | да (webhook) | —                                | Публичный HTTPS-адрес без `/` в конце |
| `BOT_MODE`       | нет          | `webhook`                        | `webhook` или `polling` |
| `PORT`           | нет          | `3000`                           | Порт HTTP-сервера |
| `WEBHOOK_PATH`   | нет          | `/webhook`                       | Путь для обновлений Telegram |
| `WEBHOOK_SECRET` | нет          | из `BOT_TOKEN`                   | Секрет проверки запросов от Telegram |
| `DB_PATH`        | нет          | `data/film.db` рядом с `main.py` | Файл БД. На bothost: `/app/data/film.db` |
| `EMOJI_IDS`      | нет          | —                                | JSON с ID премиум-эмодзи для кнопок (см. ниже) |

## Настройка на bothost

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. В панели бота откройте «Переменные окружения» и добавьте:
   ```
   BOT_TOKEN=токен_от_BotFather
   PUBLIC_URL=https://<домен-бота>
   BOT_MODE=webhook
   PORT=3000
   DB_PATH=/app/data/film.db
   ```
   `OWNER_ID` можно не задавать: по умолчанию используется 7745681987.
3. Порт приложения: **3000**.
4. Команда запуска: `python main.py` (или сборка из `Dockerfile`).
5. Папка `/app/data` должна быть **постоянной** (volume), иначе база сбросится при перезапуске.
6. В логах должно появиться `webhook установлен: https://<домен>/webhook`.
7. Проверка: `https://<домен>/health` → `ok`.

## Премиум-эмодзи на кнопках

Кнопки могут показывать премиум-эмодзи Telegram вместо обычных. Чтобы их включить:
1. Отправьте боту (от админа) сообщение с нужным премиум-эмодзи. Бот ответит его `custom_emoji_id`.
2. Добавьте в `EMOJI_IDS` JSON вида `{"play": "5368324170671202286", "vip": "..."}`.

Доступные ключи: `catalog, fire, search, vip, app, help, admin, films, team, stats, add, back, home, play, link, lock, eye, edit, pause, trash, ok, no, gift, spider, web, star, next, prev, similar`.
Если ключа нет, используется обычный эмодзи.

## Ограничения

- **Видео в Mini App до 20 МБ.** Bot API не отдаёт веб-приложению файлы больше 20 МБ. Такие фильмы открываются кнопкой «Смотреть в боте». Для больших файлов нужен отдельный хостинг.
- Баннер для Mini App загружается через сервер, токен бота не попадает в браузер.
- Фон Mini App подгружается по ссылке с pinimg. Если картинка перестанет открываться, сохраните её в проект и поправьте `--bg-image` в `index.html`.

## Команды

`/start`, `/menu`, `/vip`, `/admin`, `/add`, `/cancel`. Все действия доступны кнопками.

## Локальный запуск

Требуется Python 3.10+.

```bash
pip install -r requirements.txt
export BOT_TOKEN=... BOT_MODE=polling
python main.py
```

## Docker

```bash
docker build -t film-bot .
docker run -e BOT_TOKEN=... -e PUBLIC_URL=https://... -p 3000:3000 -v film-data:/app/data film-bot
```

## Безопасность

- Вебхук проверяется заголовком `X-Telegram-Bot-Api-Secret-Token`.
- Mini App проверяет подпись `initData` по алгоритму Telegram. Подделка и устаревшие данные (старше суток) отвергаются.
- VIP-видео отдаётся только пользователям с активной подпиской или ролью сотрудника.
- Оплата принимается только на сумму тарифа и только для того пользователя, который её создал.
