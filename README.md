# Film — бот фильмов, VIP за Telegram Stars и Mini App

Проект состоит из двух файлов:

- `main.py` — бот, платежи, API и запуск всего проекта: `python main.py`
- `index.html` — Mini App

Плюс `requirements.txt`, `Dockerfile`, `.env.example`.

## Фильмы

| Тип | Где смотреть | Пример |
|-----|--------------|--------|
| Видео в боте | в боте и в Mini App | загруженный файл |
| По ссылке | только в Mini App | TikTok, YouTube, переходник |

Доступ:

- Бесплатно — смотрят все.
- VIP — открывается за звёзды. Оплатить можно прямо в боте или в Mini App, со счёта баланса или отдельным платежом.

Ссылки VIP-фильмов никому не отдаются, пока не куплено. Для TikTok и YouTube в Mini App подставляется
официальный встраиваемый плеер. Если сайт запрещает встраивание, Mini App показывает кнопку «Открыть в браузере».

## Баланс и звёзды

- Пользователь пополняет баланс звёздами (50, 100, 250, 500) через инвойс Telegram.
- Покупка VIP списывает звёзды с баланса или оплачивается отдельно.
- Звёзды поступают на баланс бота. Владелец видит сумму в **Админ-панель → Статистика** (поле «Баланс бота в Telegram»).
  Вывод звёзд делается в Fragment/BotFather, через API его нельзя сделать.
- **Продажи** — список платежей, кнопка «Вернуть» отменяет оплату через Telegram.

## Роли

| Роль | Что может |
|------|-----------|
| Владелец (`OWNER_ID`) | Всё. Назначает админов и редакторов. Получает звёзды. |
| Админ | Управляет любыми фильмами, назначает редакторов, делает возвраты, видит статистику. |
| Редактор | Добавляет фильмы, правит, скрывает и удаляет только свои. |
| Пользователь | Каталог, VIP, баланс, поиск. |

Роли выдаются в боте: **Админ-панель → Команда**, затем пришлите Telegram ID или перешлите сообщение пользователя.
Назначать можно только роли ниже своей.

## Переменные окружения

| Переменная       | Обязательна  | По умолчанию                      | Описание |
|------------------|--------------|-----------------------------------|----------|
| `BOT_TOKEN`      | да           | —                                 | Токен от @BotFather |
| `OWNER_ID`       | нет          | `7745681987`                      | Владелец |
| `ADMIN_IDS`      | нет          | —                                 | Стартовые админы через запятую |
| `PUBLIC_URL`     | да (webhook) | —                                 | Публичный HTTPS-адрес без `/` в конце |
| `BOT_MODE`       | нет          | `webhook`                         | `webhook` или `polling` |
| `PORT`           | нет          | `3000`                            | Порт HTTP-сервера |
| `WEBHOOK_PATH`   | нет          | `/webhook`                        | Путь для обновлений Telegram |
| `WEBHOOK_SECRET` | нет          | из `BOT_TOKEN`                    | Секрет проверки запросов от Telegram |
| `DB_PATH`        | нет          | `data/film.db` рядом с `main.py`  | Файл БД. На bothost: `/app/data/film.db` |
| `BACKGROUND_URL` | нет          | стандартный фон                   | Фон Mini App |

## Настройка на bothost

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. В панели бота откройте «Переменные окружения» и добавьте:
   ```
   BOT_TOKEN=токен_от_BotFather
   PUBLIC_URL=https://<домен-бота>
   BOT_MODE=webhook
   PORT=3000
   DB_PATH=/app/data/film.db
   ```
   `OWNER_ID` можно не задавать: по умолчанию владелец 7745681987.
3. Порт приложения — **3000**.
4. Команда запуска: `python main.py` (либо сборка из `Dockerfile`).
5. Папка `/app/data` должна быть **постоянной** (volume): там база и кэш видео.
6. В логах должно быть `webhook установлен: https://<домен>/webhook`.
7. Проверка: `https://<домен>/health` → `ok`.

Видео, которое Telegram отдаёт боту, открывается в Mini App только до 20 МБ — это лимит Bot API.
Большие файлы отправляйте в боте, там лимита нет.

## Команды и кнопки

Главное меню: Каталог, VIP, Поиск, Баланс, Mini App, Помощь. Для сотрудников — Админ-панель.

Команды: `/start`, `/menu`, `/admin`, `/add`, `/cancel`.

Админ-панель: Добавить фильм (мастер: медиа → название → тип → доступ и цена → сохранение),
Фильмы (карточка: открыть, название, ссылка, цена, скрыть, удалить), Команда, Продажи, Статистика.

## Локальный запуск

Нужен Python 3.10+.

```bash
pip install -r requirements.txt
export BOT_TOKEN=... BOT_MODE=polling
python main.py
```

## Docker

```bash
docker build -t film-bot .
docker run -e BOT_TOKEN=... -e PUBLIC_URL=https://... -p 3000:3000 -v film-data:/app/data film-bot
```

## Безопасность

- Вебхук проверяет заголовок `X-Telegram-Bot-Api-Secret-Token`.
- Mini App проверяет подпись `initData` по токену бота, данные старше 24 часов отклоняются.
- Видео отдаётся по короткоживущему токену (15 минут) и только после проверки доступа.
- Токен бота не попадает в браузер: баннеры и видео проксируются сервером.
- Платежи Stars обрабатываются идемпотентно: один платёж не зачисляется дважды.
